# 邱吾权的码字台 · 使用说明

> 面向最终用户。开发与打包见项目根目录 `README.md`。

## 快速上手（3 步）

1. **选书库**：打开软件 → 右上「书库」→「选文件夹」。
   - 推荐**新建一个空文件夹**（或直接选云盘同步目录），以后所有作品都存在这里。
2. **新建作品**：左下「＋ 新建作品」，输入书名（例如 `《剑出北境》`）。
3. **开写**：点作品名进入 → 左侧「正文」→「＋ 章节」→ 中间区域开始打字。
   - 停笔约 2.5 秒自动保存；也可随时 `Ctrl+S`。
   - 底部状态栏实时显示：**光标位置** / 本章字数 / 全书字数 / 今日进度 / 连更 / 本月稿费 / 今日时长。
     - **光标**：从本章开头数到光标处的字数（口径与「本章」一致，默认非空白字符，可在设置里换成"汉字"）。选中一段文字时显示「起点–终点（选中 N）」，鼠标悬停可看到"第 X 字 / 本章共 Y 字 / 已选中 Z 字"——长章节里想回到刚才那一段很方便。

## 界面速览

```
┌ 顶部：书库切换 | 面包屑     [🎲 取名] [🗺 地图] [图谱] [统计] [设置]
├ 左侧：书库作品列表
├ 中间左：正文|大纲|人物|设定|灵感 ← 标签页切换模块
├ 中间：写作区（点章节/文档即编辑）
└ 底部：字数与目标进度条
```

- 章节目录里点**卷名**可展开/收起；点**章节**在右侧编辑。
- **切标签会记住各模块上次打开的那一篇**：在「大纲」看着某篇文档时切去「人物」，再切回「大纲」还是那一篇（那个模块还没打开过文档的话，才打开第一篇）。
- **编辑区打开哪篇，侧栏就跟着走**：标签会自动切到该文档所属模块，目录里**展开所在卷并选中那一行、滚动到可见**——搜索点结果、图谱点章节跳过来也一样，不用再自己翻目录找位置。
- 把鼠标悬停在章节上会出现：`↑ 上移 ↓ 下移 ⇥ 移动 ✎ 改名 🗑 删除`。
- **拖拽整理（正文树）**：
  - 拖动**章节**到某卷上 = 入卷；拖到顶部虚线区「正文（不设卷）」= 移出卷
  - 拖动**卷**：放到另一卷的**中间区域**（整卷变子卷）/ **上三分之一**（排它前面）/ **下三分之一**（排它后面）
  - 拖到顶部虚线区可把子卷移回顶层；卷顺序调整后自动重新编号
- 右键任意作品 → 打开 / 重命名 / 统计 / 移入回收站。

## 沉浸写作：收起两侧栏

开始码字时可以**只留正文居中**：

| 操作 | 效果 |
|---|---|
| 点书库/章节栏右上角 `❮❮` | 收成一条细竖栏（各占 46px） |
| 点细竖栏（📚 书库 / 📑 章节） | 重新展开 |
| 快捷键 `Ctrl+B` | 折叠/展开书库栏 |
| 快捷键 `Ctrl+\` | 折叠/展开章节树栏 |

折叠状态会被记住，下次打开软件保持你的选择。两栏都收起后，正文会在剩余区域**自动居中**，配合宽页面设置（设置 → 页面宽度调大）就像一张干净稿纸。

## 双栏对照：边看资料边写

写作区右侧可以开一条**对照栏**，随时看大纲/细纲/人物卡/设定/灵感，甚至另一章正文：

| 操作 | 效果 |
|---|---|
| 点编辑器右上 `▦ 对照` 或按 **`Ctrl+J`** | 打开/关闭对照栏 |
| 对照栏右上 `📚` | 选择要对照的资料（大纲/人物/设定/灵感 + 正文章节） |
| `↻` | 重新读取（资料在别处改过时手动刷新） |
| `❯` | 关闭对照栏 |

- 打开作品后默认对照「大纲」里第一份文档；上次选的资料会被记住。
- 选正文里的某一章可做**双稿对照**（例如对照旧稿改写）。
- 对照栏是**只读**的，不会影响字数统计，也不会误改你的稿子。
- 对照栏顶部 `📚/📄` 两个标签与中间的分隔条之间：**拖动分隔条可自由调整对照栏宽度**（230px ~ 窗口 70%），双击分隔条恢复默认 300px；宽度会被记住。
- 建议工作流：`Ctrl+J` 开对照栏选好细纲 → `Ctrl+B`、`Ctrl+\` 收起两侧栏 → 进入全屏专注写作。

## DeepSeek AI 写作助手（对照栏内）

对照栏顶部切到 **💬 AI 助手**，即可向 DeepSeek 提问（设定漏洞、人物弧光、起名、文笔润色、卡文求助等）。

**第一次使用，三步配置：**
1. 打开 platform.deepseek.com 注册并充值
2. 左侧「API Keys」→「创建 API Key」→ 复制
3. 回到软件，AI 助手页点右上 **⚙**，粘贴 Key、选模型 → 保存（Key 只存本机）

**对话技巧：**
- 输入框打字，**Enter 发送**，Shift+Enter 换行
- **上下文开关默认都是关的**（打开软件时不勾选），所以问一句简单问题它就是**直接回答**，不会先去读一大堆材料：
  - `📄 当前章` —— 点一下才生效：把你正在写的正文章节发给 AI 一起分析（改稿、找漏洞最有用）
  - `📑 对照资料` —— 点一下才生效：把对照栏里正开着的细纲/人物/设定一起发给 AI
  - 两个开关**再点一次即可取消**；本次运行内会保持你的选择（下次打开软件又回到"都不带"）。
  - 输入框下面那行提示会写清这次的状态：`… · 附带上下文：无（默认不带，需要时点上面两个按钮）`，勾上后变成 `· 附带上下文：当前章` 或 `当前章 + 对照资料` —— 一眼就知道它这次会读多少东西。
- 模型选择（⚙ 里）：**可以直接手填模型名**——模型下线或出新款时，把它的 API 名称填进去、点保存就生效，不用等软件更新。
  - **DeepSeek-V4 Flash（`deepseek-v4-flash`）**：快速通用，日常问答首选（默认）
  - **DeepSeek-V4 Pro（`deepseek-v4-pro`）**：深度推理，复杂设定推演更稳、稍慢
  - **DeepSeek-V4 Flash Vision（`deepseek-v4-flash-vision-exp`）**：实验版看图能力（当前聊天暂为文字）
  - ⚙ 里那三个常用款旁边有**快捷芯片**，点一下就填进框里；旧名 `deepseek-chat` / `deepseek-reasoner` 仍会自动迁移
- 顶部 `🧹` 清空对话；回复支持 Markdown 渲染（列表/代码块清晰显示）
- **每条回复都能一键存进文档，不用复制粘贴**：回复底部点 **「💾 存入文档」** → 选去处：
  | 去处 | 行为 |
  |---|---|
  | 📄 **正文** | 追加到**你正在写的那一章末尾**（保留撤销与自动保存；没打开章节时会让你选一章） |
  | 🗂 **大纲** / 👤 **人物** / 🌍 **设定** / 💡 **灵感** | 弹出标题框（自动预填回复里的标题），确认即写入对应模块；**同名文档=追加到末尾**（带"来自 AI 助手 · 时间"标注），不同名=新建 |
  旁边还有 **「📋 复制」**；写完左下目录树会自动刷新，状态会告诉你是新建还是追加、落在哪个文件
- **回复是"边写边出"的**，不会让你干等：
  - 状态行实时显示 `🧠 模型思考中… 12.3s` / `✍️ 正在输出… 18.4s · 已 320 字`
  - 推理模型（如 V4 Pro）的**思考过程**会收在上方的「🧠 推理过程」块里，点开可以边想边看
  - **等待/输出期间可以自由往上翻看前面的内容**：不会再被自动拽回底部；右下角会出现「⬇ 正在输出…（已 N 字）回到底部」，想看最新时点它即可
  - **要中断这次生成，有三种办法**：点正在输出的那条消息上的 **「⏹ 停止」**（最顺手）、点输入框上方的 **⏹ 停止** 芯片、或按 **Esc**。停止后**已经收到的内容会保留**，可以直接接着问
  - 结束后消息底部显示 `⏱ 用时 · 字数 · ≈进/出 tokens`
- **长回答不会被"写一半就断"**：单次输出上限默认 **8192 tokens**（中文约 1 token ≈ 1 字，够写几千字）；在 ⚙ 里可以调到 **16384 / 32768**（调太大而模型不支持会报参数错误，那就调小一档）。万一还是被上限截断，消息底部会出现 **「▶ 继续写」** 按钮，点一下就从断处接着写（不用再手打"请继续"）
- **输入框可调大小**：问题写得多时按内容**自动长高**（最多约六成屏高，不再需要滚动条）；也可以**拖动输入框上方那条 `⋯` 抓手**上下改高度（右下角小三角也能拖；拖过的高度会记住，下次还是这个高度）；**双击抓手**恢复自动高度
- 费用按 DeepSeek 官方 token 计费（极低），用量可在 platform.deepseek.com 看
- 隐私：只有你点开上下文开关时才会把稿子内容发到 DeepSeek 服务器，其余不联网（问句简单的就是一句问句）

## 人物关系图谱

顶栏「图谱」按钮打开整书的人物关系图（数据存于作品 `.mazitai/graph.json`，随书库一起拷贝）。

**怎么加人物和关系：**
- 在**正文里用鼠标选中一个人名**（如"林晚"）→ 文字上方弹出「＋ 建立人物关系」→ 另一方**输入即过滤**：下方列出已有的同名候选（图上人物/人物卡），**点选即连线**，避免打字多字少字造出"两个林晚"；列表无匹配时按 Enter 才作为新人物录入
- 或图谱页点「＋ 人物」手动加入
- 人物文件夹里已有的**人物卡会自动并入图里**（半透明节点），点它的状态按钮即正式纳入

**图谱页操作：**
- 人物=节点（绿=存活，红=死亡，灰=未知），关系=连线+标签
- **点一个人物 → 只看他这一摊**：他的**连线全部金黄亮起**、相关的人高亮，**其余人物与连线自动淡出**（再点空白画布恢复）。人多的时候，这是"看清某个人的关系网"最快的办法
- **✨ 自动整理（人一多就点它）**：按人物关系自动排布——**关系近的靠在一起**、同一个**阵营**（人物卡结构化字段里填的）聚成板块；上千人也能在一秒左右整理完，**结果会保存**，下次打开还是这张排布。旁边的 **「⟳ 复位排布」** 是"清空记忆、回到默认铺开位置"（不按关系聚拢）
- **人再多也放得下（画布随人数长）**：画布**不是固定大小**，而是按人数自动长大——**十几人 ~50 人**是一张小图（最小 **1440×780**）、**100 人** 1577×1168、**150 人** ≈1930×1430、**300 人** 2731×2023、**600 人** 3862×2861、**1000 人** 4986×3693（每人约 118×118 的地盘），新加的人**不会叠在别人身上**。点「✨ 自动整理」时若排布确实需要更多空间，画布还会**按实际需要撑大**（弹窗里会报最终尺寸），并保证任意两人之间至少留 **≈73px**（节点直径 48px，够站住三个字的名字）
- **名字看得清（反向缩放）**：人名和关系标签**不跟着缩放放大/缩小** —— 放大时字不会撑满屏幕，缩小时字也不会小到看不见（屏幕字号始终约 13px，千人大图看全貌也是 13px）。人很多（>140 人）又缩到全貌时，默认只显示**悬停/选中/相关的人名**（不然糊成一片）；想一次看全，点工具栏 **「🔤 名字」**（按钮变亮 = 强制显示全部人名，这个选择会记住，下次打开还是这样）
  > 说清楚一件事：**上千人的图，"一屏看清所有名字"物理上做不到**（屏幕就那么大）。软件保证的是：①谁都不许重叠；②随便放大缩小、画面都拖得动；③缩小时自动收起名字、想硬看就点「🔤 名字」。真要看人，**点一个人聚焦**（只看他那摊）或**放大某一片**最有效
- **放大看图**：工具栏 **＋ / －**，或按住 **Ctrl + 滚轮** 以鼠标为中心缩放；**⤢** = **适窗**（把整张图**正好铺满**窗口——人多时按它就能看全貌；小图不会被吹成一堆巨球）
- **拖动画面（平移）**——想看哪块拖哪块，怎么拖都行：
  - **滚轮**上下拖、**Shift + 滚轮**左右拖（触摸板双指同理）
  - **右键或中键按住拖动**：在**画面任何位置**都能拖（包括拖在人身上），右键不会弹出菜单
  - **空白处左键拖动**同样可以
  - 人物图打开时，**方向键 ← → ↑ ↓** 也能推画面（一次一小步，手不离开键盘）
  - 拖到边上会**自动刹住**：最多让画面离开内容 45% 视口，所以不会"拖丢"找不回来；缩到看全貌时**照样能拖**（旧版这时候中心是钉死的，拖不动）
- **鼠标悬停某条关系线**：该线加粗变色，两端人物高亮、其余人物自动淡化——复杂关系网也能一眼看清路径
- **拖动节点**可自由排布；排布结果**自动记住**（存入 graph.json），下次打开还是你摆好的位置
- 点人物 → 详情里可**自定义节点颜色**（颜色选择器，不选则按状态自动配色）
- 连线上 ✕ 可删除该关系
- **点某个人物** → 右侧详情出现：
  - **人物卡预览**（读取该人物的 `人物/xxx.md`），可一键去编辑或补建卡片
  - **登场章节**：自动统计他/她出现在哪些正文章节（几次），点章名直接跳去读
  - **经历过的事件**：可手写记录；或点 **「↻ 按章节抽取」**——自动扫描正文里提到该人名的句子，逐句点「记入」即存为事件（自动带上来源章节）
  - **当前状态**：点状态按钮在 存活→死亡→未知 间切换
- 「🗑 删除该人物」会连同他的全部关系线一起清除

**典型用法**：卡文时看人物关系是否自洽；长篇小说完结后梳理角色命运；查某角色首次登场与死亡节点。

### 🏷 同一个人有两个名字怎么办（王熙凤 / 熙凤 / 凤姐）

书里一会儿写"王熙凤"、一会儿写"熙凤"，图谱里就会多出一个节点、关系也多一条线。**三招解决**：

1. **别名（先防）**：点开那个人物 → 详情里 **「别名」** → 「＋ 别名」把其它叫法加上（熙凤、凤姐、琏二奶奶…）。
   - 设完以后：**再用别名加人物/加关系，认的还是同一个人**（不会又冒出一个节点）；
   - 加关系时的**候选列表也能用别名搜到**（打"凤姐"会列出「王熙凤（别名：凤姐）」，点它用的是正式名字）；
   - 人物文件夹里的卡片就算叫「熙凤.md」，也不会再多出一个半透明的"未入图"节点。
2. **⤵ 合并（已经分裂了就并回来）**：人物详情里点 **「⤵ 合并到…」** → 选目标人物 → 确认。一次会把：
   - **关系线**接到目标名下（同一个人的两条线**只留一条**，重复的自动去掉；合并后"自己和自己"的那条自动删）
   - **事件、状态史、结构化字段**并过去（重复的去掉，目标已有的值优先、缺的用来源补）
   - **物品归属、位置记录**里写着另一个名字的地方一起改成目标名字（同一件东西上撞出来的两条并成一条）
   - **人物卡**：只有一张就改名；**两张都有就把内容并进目标卡**（末尾留一行「## 合并自「熙凤」」），原卡进书库 `._回收站`（可找回）
   - **正文一个字都不动**——书里写"熙凤"就还是"熙凤"，只是图谱知道那是同一个人
   - 合并后那个旧名字会**自动变成别名**，以后写它还是认这个人
3. **🔍 找重名（把已经分裂的找出来）**：人物图工具栏点 **「🔍 找重名」**，软件会把**图谱人物 + 人物卡 + 物品归属 + 位置记录**里所有名字两两比一遍，像"熙凤 / 王熙凤"、"宝玉 / 贾宝玉"这种会挑出来，逐个问你合不合并（默认保留**名字更完整**的那个）。检查过的组合不会再骚扰你。

> 建议顺序：**先点一次「🔍 找重名」把已经分裂的收拾干净，再给主要人物补上别名**（尤其是书里常用的昵称/尊称），以后就不会再分叉了。

**典型用法**：卡文时看人物关系是否自洽；长篇小说完结后梳理角色命运；查某角色首次登场与死亡节点。

## 人物卡「结构化字段」+ 📋 人物表

人物卡（`人物/xxx.md`）一直是你自由写的 Markdown。本版在**人物图详情**里多了一块 **📇 结构化字段**，把"一眼要查的信息"变成能填、能筛、能排的字段——**卡片本身还是自由 Markdown，软件不会擅自改写它**。

**字段有哪些：**
- **12 个预设字段**：别名 / 性别 / 年龄 / 身份 / 境界 / 阵营 / 籍贯 / 外貌 / 性格 / 口头禅 / 目标 / 结局（鼠标悬停有填写提示，如「境界：修为 / 等级（修仙可用）」）
- **＋ 自定义字段**：想加"灵根 / 灵宠 / 师承 / 座驾"随便加，字段名可以随时改（值不变），不要了点 ✕ 删掉
- 留空的字段**不会存**，所以文件不会被一堆空字段塞满

**四个按钮怎么用：**

| 按钮 | 作用 |
|---|---|
| **💾 保存** | 把表单存进这部作品（`.mazitai/graph.json` 的 `people[].profile`）。人物卡没进图的"虚拟人物"点保存会**自动纳入关系图** |
| **⤓ 写入人物卡** | 把字段写成卡片里的一段「## 📇 结构化信息」。**反复写入只替换这一段**，你在卡片里手写的正文一个字都不会动；卡片不存在会自动新建 |
| **⤒ 从人物卡读入** | 反过来：读卡片里的「键：值」行填回表单。常用字段名（性别/身份/阵营/境界/修为/门派…）直接认；自己起的字段名写成 **`- **灵根**：单水灵根`**（加粗）也认。**读完要点「💾 保存」才会写进图谱** |
| **＋ 自定义字段** | 增加一行自定义字段 |

> 谁说了算？**表单/图谱是唯一真相**。你手改了卡片里那几行，记得点「⤒ 从人物卡读入」→「💾 保存」，两边就一致了。

**📋 人物表**（图谱页第 5 个标签）：把所有人的字段摊成一张表。

- 列只显示**有值**的字段（预设 + 自定义；都没填就只有姓名/状态两列）
- **点列头排序**（再点一下反向，空值永远排最后）；上面搜索框可按姓名或**任意字段内容**筛选（如输入"北境"就筛出所有北境的人）
- **点姓名**跳人物图并打开该人；**📋 复制 Markdown** 把整张表复制成 Markdown 表格，直接粘进大纲/设定
- 只有人物卡、还没进关系图的人会标「仅人物卡」（点进详情保存一下就纳入了）

## 条目追踪图（道具 / 秘籍 / 作品 / 技艺，与人物图同页切换）

顶栏「图谱」→ 顶部切到 **📦 物品图**。这一张图里能放四种**语义完全不同**的东西，靠**类别**区分（类别决定"归属怎么称呼"和"状态有哪些档"）：

| 类别 | 放什么 | 归属叫 | 状态档 |
|---|---|---|---|
| 📦 **道具** | 剑、杯、电脑、信物…… | **持有者** | 可用 / 损坏 / 损毁 |
| 📖 **秘籍** | 拳谱、功法残卷、手抄本 | **持有者** | 可用 / 损坏 / 损毁 |
| 📜 **作品** | 论文、书稿、戏本 | **作者**（可合著） | 构思 / 草稿 / 完成 / 发表 |
| 🥋 **技艺** | 拳法、功法、手艺 | **掌握者**（可多人） | 入门 / 小成 / 大成 / 圆满 |
| 🔖 **其它** | 不好归类的 | 归属 | 可用 / 损坏 / 损毁 |

**为什么分这么细？** 因为"剑"和"拳法"不是一回事：剑**只能一个人拿**（转手时旧主人自动记为历任），而拳法**师父会、徒弟也会**。如果拳法也当"独占道具"存，你一给徒弟加一条，师傅就会被写成"不再会这套拳"——历史就错了。

**怎么用：**

- **节点**：菱形，**图标就是类别**（📦📖📜🥋🔖），**颜色是状态**；人物=圆节点（现任金色连线，历任灰色）
- **加入**：正文里选中名字 → 弹窗选 **「📦 物品」**；或点右上「＋ 物品」→ **先选类别**再起名字（选「技艺 / 作品」时会**默认勾上"多人共有"**，因为它们天生可以多人都会 / 多人合著）
- **点一个条目** → 右侧详情：
  - **类别**：点一下即可改（状态会自动落到新类别的第一档，并记进历史，不会弄坏时间轴）
  - **状态**：按类别给的可选档（技艺就是 入门/小成/大成/圆满）
  - **归属方式**：勾 **多人共有** = 可同时有多位（技艺、合著）；不勾 = 独占（转手时旧的自动记为历任）
  - **归属**：不共有时按钮是「＋ 现任/转手」；共有时是「＋ 加一位掌握者」，每位现任后面有 **⇥ 结束**（= 记为"结束掌握"，带上当前章节，时间轴里会出现「归属结束」）
  - **说明**、**登场章节**（点章节跳去读）、**归属时间线**（👑现任 + 历任，可删记录）
- **类别筛选条**（画布左上角）：`全部 N / 📦 道具 N / 🥋 技艺 N…`，点一下就只留这一类（其余淡出），再点一次回到全部 —— "我这本书写了哪些技艺""哪些是真·道具"一眼看清
- **画布操作与人物图完全一致**（三张图共用同一套代码）：
  - 画布**随条目数长大**（十几条是一张小图，上百条自动铺成 2000×1500 的大图），**「⤢」=真适窗**（正好铺满窗口）
  - **自由平移**：滚轮上下 / Shift+滚轮 左右 / **右键或中键按住在任何位置拖**（含拖在节点上）/ 空白处左键拖 / 方向键 ← → ↑ ↓
  - **点一个节点 → 只看他这一摊**：相关的连线金黄亮起、其余节点与连线淡出，点空白恢复；悬停某条连线时也会临时高亮
  - **✨ 自动整理**：按归属关系自动排布，**同类别的条目聚成一板块**，结果保存（下次打开还是这张排布）；**「⟳ 复位排布」** 清空记忆回到默认铺开位置
  - **名字规则同人物图**：字不随缩放变大变小（屏幕字号恒 ≈13px）；条目多、缩得较小时自动收起名字，点工具栏 **「🔤 名字」** 可强制全显
  - 拖动节点会**记住位置**（`.mazitai/items.json` 的 layout）
- 数据存 `.mazitai/items.json`，随书库整体拷贝

典型用法：追踪"谁把剑给了谁"的完整链、一把剑从铸成到损毁；同时用 **🥋 技艺** 记录"谁会什么拳、第几章学会、第几章金盆洗手"；用 **📜 作品** 记录"谁写了哪篇论文、是否发表"（作者可多人）。

> 小提示：论文这种"又像作品又有实体手稿"的，可以分两条——**📜 作品**记作者与发表情况，**📦 手稿**（或 📖）记那份纸在谁手上、第几章被烧了。

## 位置图谱（人物/物品/位置/时间轴/人物表 同页切换）

顶栏「图谱」顶部现在是五个标签：**👥 人物图 / 📦 物品图 / 📍 位置图 / 🕰 时间轴 / 📋 人物表**

> **三张图的操作方式完全一样**（人物图 / 物品图 / 位置图共用同一套画布）：画布随数量长大、**⤢ 真适窗**、滚轮/右键/中键/方向键**自由平移**、**点节点聚焦**（相关连线亮、无关淡出）、**✨ 自动整理**（结果保存）、**🔤 名字**（名字反向缩放 + 缩小时自动收起）。工具栏那几个按钮都按"你现在打开的是哪张图"生效；时间轴和人物表没有画布，这几个按钮会自动隐藏。

- **位置 = 六边形节点（蓝）**，人物=圆节点：**现处**（蓝线）与 **曾到**（灰线，带来源章节）两种关系直观相连
- 加入：正文选中地名 → 弹窗选「📍 位置」；或位置图点「＋ 位置」
  - **一次写清层级**：输入 `武陵市/南方武陵大学`，软件会自动建好「武陵市」并把「南方武陵大学」放在它下面
- **点位置** → 详情：**位置介绍**（可编辑保存）、**上级位置**、**下级位置（N）**、**登场章节**（点章跳读）、**现驻人物**（👑）与**曾到人物**（可删记录）、**在子地点（N）**
- **点一个人物节点** → 只看他去过/所在的地方（聚焦）；想跳到人物图就**双击**他
- 「＋ 设定某人现处」：从已有角色点选谁在此地；若那人原本在别处，旧地点**自动记为曾到**并带上当前章节
- **🚶 离开**：某地「现处」行右边的按钮 = 记为"离开此地 · 行踪不明"（带上当前章节），时间轴逐章回放时能看到他从第几章起失联；之后再设定新现处即重新接上
- **双向跳转**：位置图双击人物 → 人物图；人物图点人物的「所在/曾到位置」→ 位置图
- **画布操作与人物图完全一致**（三张图共用同一套代码）：
  - 画布**随地点数长大**（上百个地点自动铺成大图）、**「⤢」=真适窗**（正好铺满窗口）
  - **自由平移**：滚轮上下 / Shift+滚轮 左右 / **右键或中键按住在任何位置拖** / 空白处左键拖 / 方向键
  - **点一个地点 → 只看它这一摊**：相关的"人在此地""上下级包含"连线亮起、其余淡出；点空白恢复
  - **✨ 自动整理**：按"人在某地 + 地点上下级"自动排布，**同一个上级下面的地点聚成一板块**，结果保存；**「⟳ 复位排布」** 清空记忆
  - **名字规则同人物图**：屏幕字号恒 ≈13px；地点多、缩小时自动收名字，点 **「🔤 名字」** 强制全显
- 数据存 `.mazitai/places.json`，随书库整体拷贝

### 📚 地点的上下级（大学属于市，市属于省）

地点可以有**包含关系**，解决"人明明在学校里，图上却只显示他在市里"这类问题：

- **怎么设**：点某个位置 → 详情里「**上级位置**」→「＋ 设为某地的下级」→ 从列表里挑一个更大的地方（列表可搜索；也可以选「（设为顶级）」清空）。新建位置时直接写 `武陵市/南方武陵大学` 也行。
- **效果**：位置图上一根**虚线 + 「属于 武陵市」**连到上级；**把人物位置记在"南方武陵大学"，他就同时算在"武陵市"里**（隔着多层也算，比如 湘西 › 武陵市 › 南方武陵大学）——
  - 人物详情与时间轴里显示**完整路径**：`📍 湘西 › 武陵市 › 南方武陵大学`；
  - 「武陵市」的位置详情与时间轴卡片会出现「**在子地点**」一栏，写着 `鹿野（南方武陵大学）`，看得见人却不会被误当成"直接在市里"；
  - 速查表也照此写（人物"所在"列是全路径，地点表多一列「在子地点的人」）。
- **更具体优先**：已经记着"在南方武陵大学"时，你就算再点一次"在武陵市"，软件**不会**把大学降成"曾到"（那等于无中生有一句"他离开学校了"），只会刷新章节；反过来先记市、再细化到大学时，就正常替换。
- **不会打结**：不能把自己或自己的下级设成上级（会给出提示）；删掉一个中间地点时，它下面的地点会自动上提给它的上级，不会失踪。

典型用法：追踪"主角此刻在哪、谁在这座城、这座城到过哪些人"，或写地理大迁移时保持人物去向一致；有了上下级，"某人在某大学/某栋楼/某个村"这种细粒度记录就不会和"在某市"打架。

## 时间轴回放（图谱页第四个标签 🕰）

图谱页顶部标签：**👥 人物图 / 📦 物品图 / 📍 位置图 / 🕰 时间轴**

拖动滑杆（或按 `←` `→`）指向任意一章，立刻看到**"写到这一章时"的世界状态**：

| 栏 | 显示什么 |
|---|---|
| 👥 人物 | 此刻**存活/死亡/未知**（色点+标签）、**所在位置**、**持有 / 掌握的条目**（带类别图标，如 🥋 澧州南拳）、**已建立的关系**、最近事件 |
| 📦 条目 | 此刻的**状态**与**归属**（道具＝持有者；作品＝作者；技艺＝掌握者，可多人，如「掌握者：刘川、张三」） |
| 📍 位置 | 此刻**谁在此地**（含位置简介） |

- 顶部「**本章变更**」列出这一章发生的事情：`人物状态 · 白泽 状态：死亡`、`物品归属 · 承影剑 持有者：祝九`、`归属结束 · 张三 不再掌握「澧州南拳」`、`人物关系 · 白泽 × 祝九 关系「师徒」`、`人物位置 · 白泽 离开 · 行踪不明`……
  - **默认只显示前 6 条**，右上/末尾会有一颗虚线按钮 **「还有 N 条 ▾」**，点一下就展开全部（按钮变 **「收起 ▴」**，再点折回去）；这个选择会记住，下次打开还是你选的样子。
  - **点错了 / 只是试一下？每条右边有 ✕ 可以删掉**（见下）。
- **🧹 清理误操作**（时间轴栏的按钮）：一键清掉"**点错了又点回来**"这类不留痕迹的改动。
- 「📍 当前章」一键跳到**你正在写的那一章**；「筛选」框可按人名/物品/地名过滤三栏
- **三栏各自滚动**：人物 / 物品 / 位置 每栏内容多了，用鼠标滚轮在那一栏里滚就行（栏内独立滚动，互不影响）
- 点人物卡片 → 跳到人物图并打开该人物详情；点条目/位置卡片 → 跳到对应图
- 顶部「◀ ▶」逐章步进（`←` `→` 同效）
- **📄 导出速查表**：把"写到这一章时"的全部状态导成一张 Markdown 速查表（概况 + 人物表 + 条目表（带**类别**列）+ 地点表 + 本章变更 + 未记章节清单）。弹窗里可**预览**、**📋 复制**、或**存入「设定」文档**——写作时贴在旁边对照，或者以后接续写时当"前情提要"看。

### 🧽 误点、试一下留下的记录怎么擦掉

**① 单条删除**：把鼠标移到「本章变更」里那条记录上，右边有个 **✕**，点它 → 确认 → 这条从时间轴上消失。删掉的是它的**原始记录**：

- 人物/条目的**状态变更历史**（删完当前状态会自动同步成剩下最后一条，不会出现"历史说活着、字段说死了"）；
- **转手/归属记录**（删掉"现任"会**回退到上一位主人**，等于撤销一次误点的转手；多人共有的只删这一条）；
- **结束掌握**记录（删掉即恢复成"还在掌握"）、**事件**、**关系**、**位置记录**（删完"现处/曾到"会重新对齐，最后剩下的那条重新变成现处）。
- 底部 ⚠**未记章节**列表里每条也有 ✕（"测试一下建的东西"常常是没记章节的）。

**② 一键清理**：**🧹 清理误操作** 会自动找出"**点了又改回来**"的抖动 —— 同一章里改了几次、但章末状态和章初一样（对回放毫无影响），列出来删掉。它会先告诉你要清几条并给几个例子，确认后才动手；**跨章的真实变化（第 3 章死亡、第 5 章复活）绝不会被动**。

> 例：白泽本来在第 4 章死亡，你在第 1 章手滑点了"存活→死亡→存活" → 点一下「🧹 清理误操作」，这 3 条抖动清掉，第 4 章死亡照样保留。
> 提示：**点同一个状态不会产生记录**（状态没变＝没变化）；所以"误点"能擦，"本来就没动过"更不会留痕。

### 🚶 离开 / 行踪不明

人物**离开某地、去向不明**时，不要用"改到别处"糊弄，直接记一下：

- **位置图**：点某地详情里「现处」那一行右边的 **🚶 离开**；
- **人物图**：点人物 → 详情里「所在 / 曾到位置」的 **🚶 离开**。
- 效果：此人从**当前章节**起显示为 **🚶 行踪不明**（不再算"在此地"），时间轴逐章回放时能看到他**从第几章起失联**；位置记录里也会留下历史。
- 之后把他**设定到某个新地点**，行踪就重新接上了（同一章里重复点「离开」不会刷出一堆重复记录）。

### 未记章节的变更：一键补记

如果某些记录没记来源章节（老数据，或当时没开着章节就改了状态），底部会标 **⚠** 集中列出。现在每条右边都有两个按钮，点一下就补好：

- **📍 记为当前章**：把这条变更记成**你正在写的那一章**（最常用，一键搞定）；
- **📅 选择章节…**：弹出**可搜索的章节列表**（带卷名与序号，如 `风起 › 第3章 重逢`），输入几个字筛选后点选。
- 补记后时间轴**立刻重算**，⚠ 条数实时下降；全部补完，底部提示自动消失。
- 注意：补记会**改变这条变更的生效章节**——补到第 3 章以后，更早的章节里就看不到它的效果了（这是正确的：时间轴要反映事实）。

### 为什么有些内容带 ⚠

时间轴靠**记录里的来源章节**判断"从第几章起生效"。规则：

1. 记录带来源章节且对得上正文章节 → **精确**（从该章起生效）；
2. 没有来源章节（或章节被改名/删除）→ 按「**从第 1 章起**」处理并标 **⚠**，底部「未记章节的变更」会集中列出，**可按上面说的两种方式一键补记**；
3. 人物/物品的**状态变更**从本版起会自动记历史（改状态时若正开着某一章，就连同该章一起记下）；**老数据**只有"当前状态"，会当作基线（补记时会自动补出一条「从该章起生效」的历史）。

> 想让时间轴精确：**开着对应章节去改**人物状态、物品归属/状态、人物现处，或加关系——软件会自动记下这一章。
> 数据仍是纯 JSON（`graph.json` / `items.json` / `places.json`），可以手动补 `chapterRel` 字段；`places.json` 里 `role:'gone'` 的记录就是"离开/行踪不明"。

- **还没进作品**：搜整个书库所有作品
- 输入即搜（中文单个字也能搜），支持任意关键字
- **多关键词**：用空格分隔多个词 = 文档须**同时包含**所有词（如 `林晚 剑客`）
- **正则**：`/正则表达式/` 或 `re:正则`（大小写不敏感），如 `/第\s*\d+\s*章/`
- 下拉结果按文档列出：显示命中行数与**命中句摘录**（所有命中的词/正则段黄色高亮）
- **点任意结果**：直接打开对应章节/文档，并定位到第一处命中（多词定位第一个词）
- Esc 或点击空白处关闭；✕ 清空

适合用来找伏笔、查人名设定第一次出场、回顾某段剧情。

## 世界地图生成（顶栏 🗺）

程序化随机生成小说世界地图（离线，点「重新生成」换一张）：

| 地图类型 | 内容 |
|---|---|
| 🏳 **国家地图** | 国家疆域划分（边界带手绘感）、每国**首府（金星）**与 2–4 座属城、山川河流湖泊 |
| ⛩ **修仙大陆** | **门派势力范围**划分 + ✦ **秘境/遗迹**标记 + 山川地脉 |
| ⚔ **江湖势力图** | 帮派势力划分与城镇分布 |

- 可选**区域数量 3–9**
- **可选地貌**（芯片多选）：🌊 海洋、🏝 岛屿、🏜 沙漠、🌲 森林、🌾 大草原、🌿 沼泽、❄ 雪原、🧊 冰川、⛰ 丘陵、🌋 火山、〰 河流、💧 湖泊、🏔 山脉
  - **一个都不选 = 全部生成**（默认）；也可只勾想要的，比如只勾"沙漠 + 森林"
  - 勾"岛屿"会自动带上海洋；点「✕ 清空（=全部）」一键恢复全地貌
  - 地貌是**噪声扭曲的色块 + 手绘符号**（沙丘弧线 / 树形 / 草簇 / 沼泽点 / 雪晶 / 冰棱 / 丘陵弧 / 火山熔岩），不是贴图
  - 雪原与冰川会自动出现在地图偏上部
- **点地图看区域详情**：点击陆地上任意位置 → 该区域高亮（其余区域蒙白、红圈定位），下方详情面板显示：
  **区域名（带颜色）、首府、属城、该区域内的各地貌及占比、相关山脉/河流/湖泊、遗迹秘境清单**，并标出"你点击处的地貌"；点海洋则显示海域与海岛数量
- **取消选中（回到未点击状态）**，三种方式任选：
  1. **再点一次同一个区域**（切换取消）
  2. **按 `Esc`**（有选中时先取消选中；没有选中时按 Esc 才关闭窗口）
  3. 点底部 **「✕ 取消选中」** 按钮
- 地图下方图例列出各区域的名字、首府与属城
- **可以按自己的设定生成**：展开「📝 按描述生成」，写一段"一个大陆、南边靠海、四个国家、北边的国家叫大商王朝有3个城市地貌是雪原…"→ 解析成约束（读不懂的用表单补）→ 按设定出图（见下节）
- **可缩放看细节**：滚轮缩放（锚在鼠标处）、按住拖动平移、双击/「⤢ 适窗」回到全图、`1:1` 看像素；缩小时属城名自动隐藏，放大后出现（见下节）
- **地图上的文字不满意可以直接改**：点那段文字 → 下方「✎ 改地名」跳到对应输入框，改完立即生效，并写进复现串（详见下节）
- 三个动作：**下载 PNG**（导出整张地图 1520×960，可插进设定或分享）、**存入「设定」文档**（区域/地貌/遗迹清单 + 随机种子 + 复现串，便于复现）、**复制地名清单**
- 地名/国号/城名/遗迹名都来自软件内置词库，可再配合顶栏「🎲 取名」微调

### 复现同一张地图（随机种子怎么用）

每生成一张地图，顶栏「**随机种子 / 复现串**」框里会自动填上一串东西，长这样：

```
seed=20395119&style=country&regions=5&features=all
```

- 它包含**四样东西**：`seed` 种子、`style` 地图类型、`regions` 区域数量、`features` 地貌选择（`all` = 全部）
- **复现**：把这串（或从「设定」文档里连那行一起）粘回这个框 → 点 **「↻ 复现」**（或框里按 `Enter`）→ **画出与原图逐像素完全一致的地图**
  - 串里带的类型/区域数/地貌会**一并还原**，所以哪怕你中途把类型改成"修仙大陆"、区域数改成 8，粘回原串也能回到当初那张
  - 只想换个种子试同一套设置：框里直接填一个数字 → 点「复现」即可
- **「重新生成」= 换一张新地图**（类型/区域数/地貌按当前界面上的设置）
- 从「设定」文档里复制出来的整行（带 `>`、反引号等 Markdown 装饰）也能直接粘，会自动识别
- 存进「设定」的文档开头就写着：随机种子、地图类型、区域数、生成时间，以及 **`复现串`** 那一行

> 用途：把满意的那张地图的复现串抄进设定文档/大纲，以后哪怕重装软件、换电脑，粘回去就能拿到一模一样的世界；想微调就在原串上改一个数字（比如 `seed=20395120`）→ 得到"同一套设定下的另一张图"。

### 改地名（自己起名，改完照样能复现）

对地图上的文字不满意？**自己改**：

- **怎么改**：
  1. **直接点地图上的那段文字**（区域名 / 首府名 / 属城名 / 遗迹名都可以点）→ 下方「**✎ 改地名**」会自动展开并跳到那一行的输入框，直接输入新名字即可；鼠标移到文字上会变成"可编辑"并有提示
  2. 或者在「**✎ 改地名**」清单里改：分 **🏳 区域/首府/属城**、**✦ 遗迹/秘境**、**🏔 山脉/河流** 三组（山脉与河流没有画成地图文字，只能在清单里改）
- **边打边生效**：输入后约 0.2 秒重绘；回车确认；**清空、或填回原名 = 恢复原名**；右上「↺ 全部恢复原名」一键复原
- 改过的名字会同步到：**地图画面、下方图例、点击详情面板、复制的地名清单、存入「设定」的文档**（文档里还会记一行"原名 → 新名"）
- **改名会写进复现串**（多出一段 `names=…`），所以粘回复现串复现时，**改过的名字会原样落回原处**；名字里的 `&`、`,`、`:`、空格等字符会自动编码，不会把复现串弄坏

> 注意：**「重新生成」= 换一张新地图，会清空改名**（槽位含义变了，硬套过去只会张冠李戴）；想保住改过的名字，请先把「随机种子 / 复现串」整串复制走（或直接「存入『设定』文档」），以后粘回来点「↻ 复现」，名字和画面一起回来。

### 按描述生成（写一段设定，自动出图）

不满足于随机？展开「**📝 按描述生成**」，写一段中文设定，让它照着画：

```
一个大陆，南边靠海。
大陆上有四个国家。
北边的国家叫大商王朝，有3个城市，地貌是雪原。
南边的国家叫南越，有5个城市，地貌是森林和草原。
山脉3座，河流2条，遗迹5处。
```

点「**🔍 解析文字**」→ 下面会列出**识别到的每一条**（哪句话被理解成了什么），以及**没读懂的句子**（原样列出，绝不瞎猜）；旁边同时出现一张**约束表单**，把识别结果摊开成可改的控件：

| 表单项 | 含义 |
|---|---|
| 形态 | 大陆 / 群岛海域 |
| 海 | 随意 / 无（内陆）/ 北边 / 南边 / 东边 / 西边靠海 |
| 地图类型 | 不指定 / 🏳 国家地图 / ⛩ 修仙大陆 / ⚔ 江湖势力图（文字里写"门派""江湖"也会自动认） |
| 每国城市数 | 留空=随机 |
| 山脉 / 河流 / 湖泊 / 遗迹 | 数量（留空=随机） |
| 区域数 | 改这里会按数量重建下面的行 |
| 每国一行 | **方位**（北/南/东/西/中 + 四角）/ **名字**（留空=随机取名）/ **城市数** / **地貌**（如 `雪原、森林`，留空=随机） |

核对/补完点「**✅ 按这份设定生成**」即可（用一份新种子生成；地貌芯片会被同步成"世界里有哪几种地貌"）。

**能听懂的说法**（可以自由组合，中英文数字都认）：

- 形态与海：`一个大陆`、`四面环海`、`群岛`、`内陆`、`南边靠海`、`东边临海`、`没有海`
- 数量：`四个国家`、`五个门派`、`三个国家`、`8 个势力`
- 命名：`北边的国家叫大商王朝`、`第三个门派叫寒山宗`、`大商王朝在北边`、`南边的叫南越`
- 城市：`有3个城市`（挂在同一句提到的那国）、`每个国家2座城市`、`共20座城市`（按国数均分）
- 地貌：`地貌是雪原`（跟同句的方位/国名走）、`北边是雪原和冰川`、`大陆上有沙漠、森林和草原`（全局）
- 山川：`山脉3座`、`河流2条`、`湖泊3处`、`遗迹5处`，写成 `3座山脉`、`两条河流` 也认

> 生成出来的地图，**约束会写进复现串**（多一段 `spec=`），所以粘回复现串点「↻ 复现」能连"哪国在哪、几座城、什么地貌"一起还原；「存入『设定』文档」也会把**出图约束**整段记在文档里。想改主意：直接在表单里改再生成，或改描述文字重新解析。

### 放大看细节（滚轮缩放 / 拖动平移）

地图画在可缩放的视口里，挤在一起时放大看：

| 操作 | 效果 |
|---|---|
| **在地图上滚滚轮** | 以鼠标指的位置为锚点放大 / 缩小（想滚整个弹窗就改在弹窗其它地方滚） |

| **双击地图** | 回到「适窗」（整张图铺满窗口） |

## 改了章节名，图谱里的"出自第几章"会跟着变吗？

**会**，而且老数据也能修好。

- 图谱里（人物关系、物品归属、人物位置）每条变更都记着"出自哪一章"。**你现在改章节名、把章节挪进/挪出卷、改卷名、重排卷顺序**，这些记录都会**自动跟着改写**——位置图的「设定某人现处」、人物图的「所在 / 曾到位置」、时间轴的章节归属都会显示新名字。
- **以前改过名留下的旧记录**：软件会按「**同一个文件夹 + 同一个章号**」这类线索把它**认回当前章节**再显示（所以界面上看到的是新章节名，不会看到一堆陌生旧文件名）。
- 想把旧记录**永久写回**当前路径：图谱页工具栏点 **「🔧 修复章节引用」** →
  - 先给你体检结果：共几条指着旧名、其中**能认回**几条、**认不出**几条，并给几个例子；
  - 确认后只改**认得准**的；认不出的（那一章可能已被删掉或合并）**原样保留，不乱改**——你可以在时间轴底部用「选择章节…」手动指定。

> 为什么会有认不出的？如果同一卷里有重复章号（比如你把两章都改成"第3章"），软件就无法唯一判断，这时它宁可不动。目录式命名越规范（`第N卷 xx/第M章 xx`），认回得越准。

## 资料模块的目录（大纲 / 人物 / 设定 / 灵感 都能用）

资料区可以像电脑文件夹那样分层：**大纲**下建「细纲」，细纲里再建「第一卷」，文档放进去。

**怎么操作**（把鼠标移到某一行上，右侧会出现小按钮）：

| 按钮 | 作用 |
|---|---|
| 工具栏 **「＋ 文档」** | 在当前模块里新建一篇文档（悬停提示会说明建的是「大纲文档 / 人物文档 / 设定文档 / 灵感文档」） |
| 工具栏 **「＋ 目录」** | 在当前模块根目录下新建一个目录 |
| 目录行 **＋** | 在这个目录里**新建文档** |
| 目录行 **📁** | 在这个目录里**新建子目录**（可多层嵌套） |
| 目录行 **↑ / ↓** | 目录之间**调顺序**（顺序记在作品的 `.mazitai/order.json`，**文件名不动**） |
| 目录行 **✎** | **目录改名**——里面的子目录和文档**一起跟着走**，位置顺序也不变 |
| 目录行 **🗑** | **删除目录**：整棵子树（含里面的文档）移入书库根目录的 `._回收站`，弹窗会告诉你有几篇文档，可按名字找回 |
| 文档行 **⇥** | 把这篇资料**移到别的（子）目录**里去；目标里已有同名会**自动加 `（2）`**，绝不覆盖 |

**几条约定**

- 列表里**目录永远排在文档前面**，两组各自按你排的顺序；没排过的按名称自然排。
- 模块根目录（「大纲」「人物」「设定」「灵感」本身）**不能改名、不能删**，防止把整个模块弄没。
- 名字里不能有 `\ / : * ? " < > |`，也不能为空。
- 删除是**移入回收站**而不是真删：书库文件夹 → `._回收站` → 找到名字类似 `《作品名》__大纲_细纲_2026-09-17T06-30-00` 的项，把里面的东西拷回原位即可。
- 早期版本用「🎬 导演」生成过「细纲」目录的话，现在可以照常改名或删除了。

## 导出 Word / PDF（可自选章节）
顶栏 **「⤒ 导出」**（作品打开时才有内容可选）。

**能做两件事**：

| 格式 | 适合 | 说明 |
|---|---|---|
| 📄 **Word（.docx）** | 投稿、给编辑改稿、自己再排版 | 标准 Word 文档，用 Word / WPS 打开就能改；**不依赖任何第三方库**（自己在软件里拼的 OOXML） |
| 📕 **PDF** | 打印、投稿要求 PDF、发给别人看版式 | A4 版式固定，**每章自动从新的一页开始** |

**怎么用**：

1. 点顶栏 **「⤒ 导出」**；
2. 填**署名**：**书名** 与 **作者** —— 会印在标题页上，也会写进 Word 的「文档属性 → 作者」。
   - 打开时自动填好：优先用这部作品存过的（`book.json`），其次是上次导出用过的；**作者留空就不写作者**（不会再出现"码字台"）
   - 导出成功后这两个值会**记到这部作品上**，下次导出不用重填
3. 选**格式**（Word / PDF）；
4. 选**章节**：
   - 章节按**卷分组**列出来（右边显示每章字数）；卷头的复选框 = 整卷一键勾选/取消（半选状态会显示成横杠）
   - 快捷按钮：**全选 / 全不选 / 只选当前章 / 当前卷**
   - 底部实时显示「已选 N / 共 M 章 · 约 X 字」
5. 四个开关：
   - **📃 标题页**（书名 + 作者 + 导出日期，单独一页）
   - **↕ 每章新起一页**（长篇小说建议留着）
   - **↩ 回车间分段**（**默认开**）：正文里按一次回车就是一个新段落 —— 和编辑器、预览里看到的完全一致。**如果你是从别处粘来的稿子、段落内部本来就有软换行（一行的字没写完就换行），把这个关掉**，就按 Markdown 标准来（空行才分段、段内的连续几行会合成一段）
   - **⇥ 首行缩进两字**（**默认开**）：中文小说的排版习惯；段首本来就打了全角空格的会自动去掉，不会缩成四格
5. 点 **「开始导出」** → 选保存位置（默认建议放桌面）→ 完成后弹窗告诉你有几章、多大，并可直接 **「打开所在文件夹」**。

**排版规则**（写的 Markdown 会照着排出来）：

- 正文用**宋体、12pt、1.5 倍行距**，A4 纸、四边 2.5cm 左右页边距；**每段首行缩进两字**；
- **分段规则**：**正文里按回车即分段**（和软件里看到的段落一模一样）；空行不会额外多出空段；
- `#`~`####` → Word 的标题 1~4（PDF 里对应 h2~h5，会自动"跟随上段"不孤行）；
- `**粗体**`、`*斜体*`、`` `代码` `` → 真正的粗体/斜体/等宽字体；
- `- 列表` / `1. 列表` → 真正的项目符号与编号（Word 里是可编辑的列表，不是假圆点）；
- `> 引用` → 缩进的引用样式；` ``` ` 代码块 → 等宽小字；
- `| 表格 |` → **Word 表格**（带边框）；
- `---` → 一条分隔线；
- 章节正文开头如果自带 `# 第1章 XXX`（和文件名同款），导出时会**自动去掉**，不会出现两遍章名。

> 导出**不改动**书库里的任何文件，只是读出来另存一份。正文里的 `[[双链]]`、脚注之类目前按普通文字导出（以后需要可以再加）。

顶栏搜索框右边的 **⇄** 按钮，或按 **`Ctrl+H`**。找到的东西可以一处一处换，也可以一次全换。

**怎么用：**

1. 填「**查找**」和「**替换为**」（替换为留空 = 删掉找到的内容）；
2. 选**范围**：当前作品的正文 + 资料（默认）／仅正文／仅资料／只有当前打开的这一篇；需要区分大小写就勾上；
3. 点 **「🔍 查找全部」** → 出现的是一份**清单**：按文档分组（📄 章节 / 🗂 大纲 / 👤 人物 / 🌍 设定 / 💡 灵感），每处一行**上下文**（`第 N 行  …命中…`），后面还跟着 `→ 换成什么` 的样子；
4. 然后三种换法任选：
   - **全部换**：点「**✅ 替换全部命中（N 处）**」；
   - **只换一篇里的**：文档那一行的「**替换本篇全部**」；
   - **只换某几处**：某一行的「**替换**」按钮（只换这一处），或者取消勾选不想换的、点「**✔ 替换勾选的 N 处**」（默认全勾）。
5. 换完**清单会按新内容自动重算**，剩下的命中数实时更新；后悔了就点「**↶ 撤销上次替换**」。

**匹配规则**

- 默认**整串精确匹配**：`云舟真人` 只会匹配连续的这四个字；**空格也算在匹配串里**（这点和顶栏「搜索」不同 —— 搜索会把空格当"多个词同时包含"，替换必须是连续一整段）。
- `/正则/` 或 `re:正则` 表示用正则，例如 `re:第\d+章`；正则模式下**替换为里可以用 `$1 $2` 引用括号里的分组**（如查找 `/(小)(明)/`、替换 `$2$1` → 「小明」变「明小」）。
- 精确模式下 `$` 不是特殊字符，写 `$100` 就是 `$100`。

**放心用的三个保证**

- **不会弄乱你正在编辑的那篇**：替换前会先把编辑器里未保存的内容存盘，替换后编辑器里的内容会立刻变成新内容（不会出现"2.5 秒后自动保存又把旧内容写回去"）。
- **不算进今日字数**：替换是机械编辑，不是写作进度 —— 统计里不会因为一次改名就多出几千字；但章节字数、全书字数会照实更新。
- **可以撤销**：最近一次替换能整体回滚（改前内容在内存里，关掉软件就没法撤了；改动特别大时软件会提示"这次没有保留撤销"）。

> 单处替换带校验：万一文件在别处被改过，软件会提示「文档已变化，请重新查找」，而不是照着旧位置乱改。
> 大量改名很方便：例如把「云舟」改成「青舟」、把某个错别字一次修完、把所有章节里的某个称呼统一 —— 先看一眼清单再点替换即可。

## 统计都代表什么
- **今日净增**：今天让正文实际**变长**的字数（非空白字符）。删掉的会扣回来，不虚报。
- **每日目标**：达标后状态栏出现 🎉。连更按「当天净增 > 0」的天数计算。
- **热力图 / 30 天柱状图**：都按当日净增统计。
- **里程碑**：从你开始用本软件记录起，累计净增到 1 万 / 5 万 / 10 万…字的日期。
- **本月稿费**：本月净增字数 ÷ 1000 × 千字单价（单价在作品设置里改）。
- 界面上的「本章 / 全书字数」可在设置里切为「仅汉字」口径；历史统计不受影响。

   ├─ book.json            作品设置（目标字数、单价）

   ├─ .mazitai/graph.json   人物关系图、状态变更历史、人物结构化字段
   ├─ .mazitai/items.json   条目（道具/秘籍/作品/技艺）与归属历史
   ├─ .mazitai/places.json  位置（含上下级）、现处/曾到/离开记录

## 小提示

- 建议书库文件夹放云盘（坚果云等），正文是普通文件，同步零冲突、随时可恢复旧版。
- 不要手动改 `.mazitai` 里的内容（真要手改就先备份，改完重开应用）；`. _回收站` 定期手动清理即可。
- **人物结构化字段**存在 `.mazitai/graph.json` 里（不是存在人物卡里），所以要"卡片里也带上这些信息"就点「⤓ 写入人物卡」；卡片里手改了字段名那几行，点「⤒ 从人物卡读入」再保存即可同步回来。
- **拳法 / 论文这类东西放哪**：放进「物品图」但**要选对类别** —— 拳法选 **🥋 技艺**（勾上"多人共有"，师父和徒弟就都在）、论文选 **📜 作品**（归属是「作者」，可多人合著）；只有实体道具才用 **📦 道具**。选错了会怎样：独占类别的条目在加第二个人时，会把第一个人记成"不再持有"。老条目点一下类别 chip 就能改过来。
- 界面文字全是中文，字体与排版随时可调，调到像「看一本书」那样舒服再写。

## 遇到问题？

- 应用打不开 / 闪退：确认是从 `release` 安装包安装；还不行就删掉配置目录 `%APPDATA%/邱吾权的码字台` 重开（只丢界面设置，不丢稿子）。
- 想找回误删：书库文件夹 → `._回收站` → 按时间找文件拷回 `正文/` 对应卷即可。
